COMPUTER QUERYDEV

Starting…
    Preview. Models make mistakes, so verify important facts. All your data stays on your device.

    Settings

    Settings, notes, and chat history are saved in this browser's localStorage. Model weights are saved in the browser's Cache Storage. Nothing is sent to a server.

    Model

    Choose the model from the menu at the top of the page. Bigger models follow instructions better and know more, but download more and run slower. Auto picks one based on the device check below.

    Weights are stored in 4 bits either way; this sets the precision used for the math. Auto uses f16 when the GPU supports it.
    Checking…
    The most tokens the model can see at once: system prompt + notes + history + reply. Larger uses more GPU memory. Changing it reloads the model.

    Sampling

    Same seed + same settings + same input = same output. Try temperature 1.0 with and without a seed, then ask the same question twice.

    Learning view

    Style enforcement

    Checks for first-person words, feelings, greetings, and flattery. Code is always ignored. A small model is a noisy judge: it will sometimes pass or fail an answer wrongly.

    Turn these off to see how often the raw model breaks the style rules.

    System prompt

    Instructions placed before every conversation. Edits apply to the next message.

    Notes (memory)

      Data

      Calculating storage…

      Export/Import moves settings, notes, and chat between browsers. Reset keeps downloaded models; use /reset in the chat to delete those too.

      Dev: model load timings

      Dev mode is on (turn off with ?dev=0). Every model load is recorded in this browser's IndexedDB. "cold" = weights downloaded; "warm" = weights already cached.

      Dev: style checks

      Every style check is recorded: verdicts, rewrites, and timings. Use the ✓/✗ buttons under each reply to label whether the shown answer is in style; the summary then shows how often the check agrees with you.
